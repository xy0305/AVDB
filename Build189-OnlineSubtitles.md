# Build 189 · Optional online subtitles

- Independently implemented Xunlei anonymous HTTPS name-search protocol; `uzzyj333/xunlei-subtitle` has no declared license and none of its code is copied. ThunderCat declares MIT; consulted protocol principles only, no code copied.
- Explicit per-search consent, public movie number default for 115 playback. Generic playback defaults to empty query; never infer filenames, private paths or URLs. No CID/GCID calculation, Range access, video downloads, automatic selection, analytics or persistent subtitle files.
- Fresh ephemeral sessions, system TLS, no credentials/cookie store/cache/115 headers. Search 15s request /25s total, 1MiB JSON, first 500 rows, up to 80 unique safe candidates. Single in-memory search cache, 120s TTL, cleared on video switch. Selected download 8MiB maximum, same timeout; validates initial URL and every redirect, exact HTTPS CDN plus known hash paths only. Only one selected subtitle is downloaded, no synthesized fallback URL.
- Independent limited text parser: SRT, VTT, basic ASS dialogue. No ASS styling, animation, positioning, karaoke, drawings, attachments or external resources. HTML/XML errors, binary controls, oversized lines and cue sets rejected. UTF-8 plus round-trip validated GB18030/Big5; ambiguous automatic encoding rejected with explicit encoding picker. Up to 20,000 cues, 16KiB line, 8,192 characters per cue, two-second parsing budget. Parsing occurs off main actor.
- Own SwiftUI overlay reads real KSPlayer media time every 100ms; does not alter underlying embedded subtitle behavior, default decoder, LUT, audio session or 115 original-file strategy. Overlapping text limited to four cues. Offset -120 to +120s, positive means later, with reset and explicit disable. PiP/AirPlay external presentation not guaranteed (shown in panel).
- Safety-first identity policy: URL, public identity or progressID change clears subtitles and cancels old tasks. 115 already uses `.id(url)`, so quality switching ALSO clears subtitles. No unreliable same-file guessing or subtitle retention across quality changes. Generation guards block delayed stale search/download/parser completion.
- Added deterministic native Swift safety/parser/network fixture regression, iOS hosted model tests and native UI consent/search/select/offset/disable test. All previous regressions retained. Production dependency remains KSPlayer >=2.3.4 upToNextMajor; CI records actual resolver output.
- Normal certificate verification from iSH Python: public query `Oppenheimer 2023` HTTP200/code0/56 rows; `ABP-123` HTTP200/code0/0 rows. No actual copyrighted subtitle downloaded. Git HTTPS transport failed local CA validation, so publication uses GitHub Git Data API with normal verified TLS and force:false. CI runs an optional system URLSession TLS search probe; third-party availability is not a release gate.
