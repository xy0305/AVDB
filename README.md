## 外部数据库手动令牌（1.0.2 build 177）

在「我的 → 来源 → 外部数据库」启用服务、填写服务器根地址及新令牌，然后点击「保存设置」。安装包不内置令牌，也不迁移历史源码凭据；首次安装默认停用且未配置令牌，不会访问外部数据库。

令牌通过 SecureField 输入，仅保存至本机 Keychain（解锁可用、仅本设备、不进行 iCloud 同步），不会回显。输入留空保存保留已存令牌；只有显式「清除已保存令牌」并确认才删除。返回放弃未保存的输入。更改服务器时必须重新输入令牌，或先清除原令牌，防止误发到新服务器。修改保存立即取消旧请求；详情按配置代际更新，不会用旧结果覆盖新配置。未启用、无令牌时不请求；鉴权、网络、响应格式和钥匙串失败明确提示，不伪装成功空数据。

服务器仅允许 http/https 根域名或 IP 加端口，不接受账号、路径、查询或片段。保留原 HTTP 服务器地址供手动配置；**HTTP 未加密，令牌及查询内容可能被窃听或篡改**。钥匙串只保护本机存储，不保护 HTTP 传输，建议使用可信 HTTPS。请求通过 `X-API-Key` 头发送凭据，禁用缓存、Cookie 和自动凭据存储，拒绝所有重定向，错误不输出响应正文或令牌。

保留原生详情磁链合并与用户主动推送 115、MissAV 影片/女优排行、播放器手势、音频生命周期和 LUT。离线回归使用合成 URLProtocol 与隔离令牌存储 stub，不调用真实数据库或 115 写接口。入口 UI 测试由 iPad 模拟器 CI 执行，不代表真机或真实账号验收。详见 [Build177 安全及验收说明](Build177-ExternalLibrary.md)。

## MissAV 新增排行（1.0.2 build 175）

保留原 AVDB 全部排行榜及 JAV Ranking 入口，在「排行榜」新增「MissAV 日 / 周 / 月排行」。MissAV 仅提供排行、原站封面标题与番号，不替换 AVDB 数据源、不注入上传 JS、不新增播放系统。

点击 MissAV 条目 → 按完整番号搜索现有 AVDB/JavDB 数据源 → 唯一精确匹配进入原生影片详情 → 在真实磁链列表选择资源推送 115。继续使用「我的」已配置的 115 Cookie 和目录、原生离线界面；无匹配时提供该番号原生搜索结果供手动核对，绝不自动选择无关第一条。

实站对照确认 missav.ws 的新旧 UA 均遇 Cloudflare 403，参考 JS 的 missav.fans / missav.media 原生 GET 返回真实 200 列表。build175 对齐标准浏览器头、隔离站点会话 Cookie，修复正常被动 Cloudflare JS 被误判验证及规范化分页路径；默认采用已验证 missav.fans，不自动切镜像，保留已保存来源。若已保存 missav.ws，可在 MissAV 设置恢复默认后保存。真正的 challenge 仍明确提示重试/浏览器核对，不绕过验证码、不导入浏览器 Cookie、不声称真机连通。详见 [诊断、实测与验收边界](Build175-MissAV.md)。
