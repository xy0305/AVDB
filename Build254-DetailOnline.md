## Safety and verification limits
Ephemeral anonymous URLSession; no account/session/browser cookie import; default TLS; no automatic redirects; size, request/operation and manifest graph bounds; all metadata/media DNS rejects private/reserved/FakeIP, never bypassed. No remote JS engine, login, DRM, captcha, challenge, private-network exception, or media guessing. Standard public identity AES-128 keys are checked for 16-byte validity only, never saved/logged/decrypted; no video segment downloads by validation. Manifest media/rendition/relative/key URLs must remain on the exact issued HTTPS origin. Segment DNS uses the same preflight host; DNS preflight is not pinning. Native KSPlayer/AVFoundation owns subsequent playback requests; its future DNS/redirect decisions are not intercepted by this adapter. This inherited limitation is not represented as an end-to-end network sandbox.

Search hits, static media resolution, HLS validation and actual first frame are separate stages. No first-frame playback is established by an HTML/manifest 200. Real anonymous shell metadata probes on FNS-249: Jable/MissAV 403, MemoJav 404; MemoJav START-642 detail 200. 123AV search/detail/embed/stream metadata 200.
