# Native LUT (original numeric engine)

Adapted from supplied `网页视频实时 LUT（v6.7.5）`, original metadata `@author You`, `@version 6.7.5`; complete unexecuted source in `THIRD_PARTY/lut-v6.7.5.txt`. No license was present in that source. Redistribution permission has not been independently verified; no license is invented for it.

`AVDB/Resources/OriginalLUT.js` directly reuses the complete original pure numeric section: all three templates/target sets, center high-match ranges, staged predictParams search, dynamic highlight target, high-highlight scene branches, extra temperature reduction, severe saturation, automatic highlight compensation, luminance guards and parameter balancing. Original scalar processing and generateLutData remain unchanged, including Float32Array rounding, cache, thresholds, ordering and stopping conditions. Sampling directly reuses original capture post-landmark body, dynamic Cr quantiles, skin rejection, high-RB/high-pixel statistics, global highlight ratio and minimum 150-skin-pixel rejection. Single-frame aggregation uses original max-3000 then coarse-400 deterministic subsampling and original forced high-match routing. No DOM, MediaPipe loader, WebGL, network or userscript init is evaluated. Each invocation owns an isolated JavaScriptCore context; analysis executes on the detached background worker. CoreImage receives original RGB cube expanded to RGBA Float32, in sRGB.

Vision supplies a face rectangle instead of MediaPipe 0.10.14 face-landmark extrema: ROI parity is NOT claimed. AVPlayer/CI decoding, sRGB conversion, CGContext versus canvas rasterization, orientation, pixel rounding and GPU interpolation may differ. Numeric parity means identical input pixel arrays and ROI, not equal analysis results from arbitrary browser/native frames. UI labels this difference. No actual native MediaPipe integration is present.

`scripts/test-native-lut.py` independently evaluates numeric functions from the supplied full original source in Node and compares deterministic dark/bright/high-match/yellow/black/white/red fixtures under all three modes: exact parameter/statistic equality and all RGB entries in 21 complete 33-cubes. macOS CI additionally invokes the bundled JavaScript via native JavaScriptCore and compares search parameters and LUT scalar samples against the Node oracle (1e-7). Linux only executes Node; it does not claim native JSC verification.

Supported scope remains composable SDR AVPlayer assets. HLS, noncomposable streams and PQ/HLG HDR are disabled. No cloud writes are introduced. Remote composition, image orientation and visual color fidelity require device testing; compilation and numeric parity are not end-to-end runtime validation.

KSPlayer remains an external GPL-3.0 dependency: preserve its notices/license and provide corresponding source for the exact application and dependency revision with any binary distribution. Its GPL notice is not a claim that the supplied userscript is GPL licensed.
